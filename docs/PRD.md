## 目标与用户
为女朋友制作一份温馨、可长期收藏的生日礼物。只有制作者和收礼人两种使用情境，不做注册、社交平台或复杂后台。

## 页面与流程
1. 首页：生日祝福、昵称、生日日期、手绘蛋糕，点击许愿出现短暂庆祝效果。
2. 冬日旅程：在中国地图上从西安拖动雪花到沈阳、济南、广元、重庆；沈阳展示飞机抛物线，后三地展示火车路线。
3. 旅行青蛙：每条火车路线到站且持久化成功后，单独在对应城市旁显示青蛙；西安使用爱心入口。广元、重庆、济南均展示同名地点故事，不互相混用。重进页面恢复解锁状态；未完成不提前展示。
4. 蛋糕台：完成沈阳飞机路线后出现；抹奶油需要拖动形成 6 个奶油点，裱花需要点击 3 次，输入愿望后显示在蛋糕后方安全留白区域，插蜡烛需要点击 3 次；四步完成后显示烟花和许愿。
5. 回忆相册：地点列表 → 该地点的故事卡片 → 故事内照片与逐张说明。详情提供返回当前地点故事列表入口。制作者可整理未解锁地点，分享游览模式只开放已到达地点。
6. 生日信：可自定义称呼、正文、落款。
7. 整理礼物：修改生日信息，新增/编辑/删除照片故事，备份、恢复、导出分享页面。

## 功能要求与验收
| 功能 | 验收标准 |
| --- | --- |
| 图片上传 | 支持一次多选 JPEG/PNG/WebP，单张不超过 15 MB；一个故事最多 30 张，缩放至最长边 1600px，保存 JPEG；损坏/不支持的文件显示原因 |
| 故事 | 一个故事可关联 1–30 张图片；标题必填，最长 50 字；日期可选；简介最长 1000 字；可编辑和确认删除 |
| 编辑能力 | 支持换地点、自选封面、故事上移/下移；照片追加/删除/替换/前后移动、独立说明（300 字以内）；保存前仅为草稿 |
| 地点扩展 | 页面新增地点、名称、到达方式、地图坐标；地图节点、路线与故事选项自动读取；已有内容不变 |
| 路线持久化 | 到站后写入成功才解锁；失败可重试；同一地点只有一个标记；分享文件保存独立游览进度 |
| 个性化 | 昵称、生日、寄语、生日信、落款可保存并刷新保留 |
| 本地保存 | IndexedDB 保存数据；写入失败不伪报成功；清空浏览器数据会丢失内容 |
| 备份恢复 | 导出 JSON，恢复前验证内容并确认覆盖；失败保留原数据 |
| 分享 | 导出独立 HTML，内嵌照片、样式、数据和脚本；离线可打开，无编辑入口 |
| 移动端 | 360px 起无横向溢出，弹窗可滚动、键盘可操作，尊重减少动画设置 |

## 设计方案
色彩：信纸白 #fffaf7、花瓣粉 #f8e8ec、玫瑰 #a54965、深莓 #4d3541、鼠尾草 #768571。
字体：中文标题使用系统宋体/衬线，正文系统无衬线，英文装饰使用 Georgia。
布局：居中的生日祝福与蛋糕 → 左对齐相册标题与三列照片 → 居中的信纸。移动端单列。留白优先，照片呈现原始比例详情。
设计复核：保留用户要求的柔和温馨配色；用手绘蛋糕和真实可编辑的信替代通用营销模块，不堆叠自动动画，不引入小游戏或统计面板。

## 技术与边界
数据版本 3：`places[]` 管理地点与路线参数；`stories[]` 用 `placeId` 关联唯一地点，含 `coverId` 和 `order`；`photos[]` 用 `storyId` 关联唯一故事，含 `src`、`caption`、`order`；`unlocked[]` 保存已完成路线地点编号。备份恢复校验外键、封面归属与唯一编号。版本 1 自动归入西安，版本 2 保留地点分组；迁移前原始内容留副本，不静默丢弃异常记录。

原生 HTML/CSS/JavaScript，无构建依赖、第三方 CDN、远程图片或统计。开发入口可直接打开 index.html，推荐固定 localhost 地址以稳定浏览器存储来源。照片“上传”是导入本机浏览器，不上传云端。不同设备不自动同步；交付收礼人使用导出的 HTML。公开托管没有访问控制，个人照片建议私下传递文件。分享文件包含照片和信，持有文件的人均可阅读。

不包含：账号、多用户权限、云存储、在线协作、自动播放音乐、生日推送、公开发布。真实姓名、生日和照片由用户在页面内填写，不使用他人私人照片作为示例。

## 圣诞视觉要求（新增）
- 全站采用温暖的冬夜圣诞氛围，加入圣诞树、圣诞礼盒、圣诞老人、壁炉烤火和飘雪。
- 元素使用本地 HTML/CSS 绘制，不依赖远程图片、字体或 CDN；分享导出的单文件 HTML 也必须保留完整氛围。
- 装饰层不可拦截鼠标和触摸事件，地图、青蛙、回忆故事、照片上传与冬日蛋糕操作保持可用。
- 移动端装饰缩小并固定在边缘，不能遮挡主要内容；支持减少动态效果设置。
